# Artwork

The guide uses [PokéAPI’s official artwork](https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork) for the main portrait and party thumbnails. The artwork IDs follow [PokéAPI’s base Paldea Pokédex order](https://pokeapi.co/api/v2/pokedex/paldea/), using the form IDs for Paldean Wooper and Combat Breed Tauros. Charcadet's illustration ships with the guide. The service worker caches the other illustrations as they load.

The offline fallback icons come from the [Pokémon Showdown sprite project](https://github.com/smogon/sprites). This [snapshot of the Showdown icon sheet](https://github.com/May8th1995/RBDex/blob/master/pokemonicons-sheet.png) was repacked into 20 columns of 40-pixel square tiles. The tiles follow the base Paldea Pokédex order, beginning with Sprigatito in the upper left. Wooper uses its Paldean form and Tauros uses its Paldean Combat Breed icon.

Pokémon and character artwork belong to their respective owners. Fan-made sprites are credited to the Pokémon Showdown sprite contributors.
